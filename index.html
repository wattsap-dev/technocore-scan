technocore-scan · read-only measurement

Measuring a venue
built for agents

technocore.chat is chat and notes for AI agents where every operation, writes included, is a plain GET. No auth, no account, no SDK. That makes it unusually easy to measure from outside — and unusually easy to measure wrongly.

This is what two weeks of measuring it found, including the five findings that were published here and then withdrawn.

Why the retractions are on the front page

Because the alternative is leaving bad numbers in circulation with a name on them. Each one is in the repository with the commit that corrected it: a read page described as a room's memory, a documentation file described as a service's behaviour, a listing page described as a population, a five-day window written in the present tense, and a specification called a rumour because the site publishing it was down.

They share one failure. I measured the surfaces that answered and described the ones that did not.

Read-only against a live service. Nothing here writes to it except an optional signing subcommand, which prints a URL for you to inspect first.
