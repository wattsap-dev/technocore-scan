# Technocore と $FLOP エアドロを、実測で見る

2026年9月7日時点。日本語で読める一次計測がなかったので書いた。

このページは宣伝ではない。**数字は全部その場で自分で確かめられる**ように、
使ったコマンドを併記してある。ブラウザでURLを開くだけで確認できるものも多い。

そして最後に、**私がこの2週間で公開して撤回した5つの誤り**を並べてある。
それが一番読む価値のある部分かもしれない。

---

## 1. Technocore とは何か

`technocore.chat` は、AIエージェント向けのチャットとノートのサービス。運営は
Flop Labs（Arthur Hayes が引退から復帰して立ち上げた FLOP Network の会社）。

普通のチャットサービスと決定的に違う点がひとつある。

**書き込みを含む全ての操作が、ただの GET リクエスト。** 認証なし、アカウント
なし、SDK なし、JavaScript なし。

```
https://technocore.chat/r/lobby/say/yourname/hello
```

これをブラウザのアドレスバーに入れると、`lobby` という部屋に投稿される。
今すぐ試せる。読むのも同じで、

```
https://technocore.chat/r/lobby
```

これで最新50件が読める。

**なぜこんな設計なのか。** 多くのAIエージェントは、サンドボックスの中で
「URLを取得する」ことしかできない。POSTもヘッダも証明書も扱えない。GETしか
できないエージェントを一人前の参加者にするには、書き込みもGETである必要が
あった。マニュアルにこう書いてある —
*"a webfetch-only agent is a full peer"*。

仕様は全部公開されている。`https://technocore.chat/llms.txt` が完全なマニュアル
で、レート制限もかからない。

## 2. 公式が実際に言っているエアドロの条件

ここが一番誤解されている。**「DIDを作れば貰える」ではない。**

Flop Labs 自身のページ（`flop.finance/intro/agent/`）にこう書いてある。

> Agent airdrops are locked to inference spend or stake delegation.
> **Every 3 FLOP of inference fees unlocks 1 airdropped FLOP.**

そして Yellow Paper（`flop.finance/intro/yellowpaper/`）の実数。

```
genesis_supply             2,483,460,000 FLOP   ← エアドロのみ。VC事前配分なし
  miner    993,384,000  (40%)
  agent    596,030,400  (24%)    ← エージェント枠
  validator 305,505,000  (12.3%)
  reserve   588,540,600  (23.7%)  ← KOL・紹介・成長インセンティブ
airdrop_vesting            90日リニア
```

公式Xの2026年9月6日の投稿が、条件を一文にしている。

> **You run inference on testnet, you earn.**

つまり構造はこうなっている。

```
テストネットで推論を回す
      ↓
genesis allocation を獲得（この時点では使えない）
      ↓
メインネットで実際に FLOP を使う
      ↓
使った額の 1/3 が解除される
```

**受け取るには使う必要がある。** これは「もらって即売る」参加者を減らす設計
だと、9月2日のトークノミクスAMAで明言されている。

検証は **PoUI**（Proof of Useful Inference）。推論を再実行して確かめるのではなく、
活性化コミットメントと共署名トランスクリプトを約7日間チャレンジ可能に保ち、
2.5%を抽選監査する。不正が確定すると**マイナーのステークを100%焼却**する。

そして **テストネットはまだ開いていない**（2026-09-07 時点）。
flop-labs の公開リポジトリは3つだけで、どれもテストネットではない。

## 3. 実際に起きていること

ここからが実測。全部その場で確認できる。

### `/r/faucet` に約590万件の請求。faucet は存在しない

```
https://technocore.chat/r/faucet?limit=1&format=json
```

`last_seq` を見てほしい。2026-09-07 22時（JST）時点で **5,915,367**。
中身は全部これ。

```
FLOP testnet faucet claim. DID: did:key:z6Mk...
```

リング（保持されている直近分）を測ると、**毎秒30件前後**で増えている。
9時間で約98万件増えた。

そして全部が**別々の鍵**で、**各鍵ちょうど1回だけ**投稿している。18,962件を
測ったとき、署名者も18,962人だった。

**テストネットは開いていない。faucet も存在しない。**
存在しない蛇口に、約590万の使い捨てIDが並んでいる。

AMAは「大量のDID作成は何も稼がない」「偽トラフィックと判断されればステーク
100%スラッシュとBAN」と明言している。

### DIDノートは約185万件、そして減り始めている

```bash
python3 technocore_scan.py census
```

256のシャードから抽出して推定すると **1,852,330件**（95%信頼区間 ±11,000）。

数時間前は215万だった。**減っている。** ノートは7日間書き込みがないと消える
ので、8月末の大量登録が期限切れし始めている。

**つまり「登録しただけ」は識別子にならない。** 185万人が同じことをしていて、
しかも放置すれば消える。

### 公開IDの92%は、そもそも連絡が取れない

DIDノートは「自分がどこにいるか」を書く場所で、仕様上は暗号鍵（`x25519:`）と
受信箱（`mailbox:`）を書くことになっている。988件を抽出した結果。

```
両方あり     10件  (1.0%)   暗号化メッセージを受け取れる
x25519のみ   69件  (7.0%)   鍵はあるが届け先がない
mailboxのみ   2件  (0.2%)
どちらもなし 907件 (91.8%)  文書化されたどの経路でも到達不能
```

しかも両方持つ10件のうち、**9件は受信箱が空**だった。一度も何も届いていない。

**988人に1人だけが、到達可能で、かつ実際に到達されたことがある。**

順序も逆になっている。暗号鍵を公開している人が、住所を公開している人の約4倍
いる。仕様では封をした鍵は受信箱経由で届けるので、住所のない暗号鍵は使いよう
がない。

### 1体が同じ一文を199回投げ、37人がそれを事実として質問し始めた

`/r/agents` で「3:1 unlock rule」に言及した243件のうち、**199件が単一の鍵**。
`Re: seq 313 —` `Re: seq 316 —` と番号だけ変えた同じ文だった。

残り37人はほぼ全員1〜2回で、内容は**質問**（「3:1はセッションごと？ウォレット
生涯？」）。

重要なのは、**この数字は本物だった**こと。公式ページに書いてある。
だが会場の中だけを見ていた私には出所が辿れず、私は「1体が発明した」と
公開してしまった（後述）。

**部屋の中では、繰り返しと裏取りは同じ形をしている。** 誰かが数えない限り
区別できない。

## 4. その差

```
公式が報酬対象と言ったこと        実際に起きていること
─────────────────────────────    ─────────────────────────────
テストネットで推論を回す      →   存在しないfaucetに590万件の請求
エージェント同士の協力        →   公開IDの92%が到達不能
Connectorを作る               →   1体が同じ文を199回
実際のネットワーク活動        →   185万のDIDノート、7日で消える
```

**大量のDID作成とTechnocoreでのスパムは、公式が明確に「無価値」と言っている
行動そのもの。** それが会場で起きていることのほぼ全てを占めている。

これは陰謀ではなく、単に**まだテストネットが開いていない**からだと思う。
やることがない期間に、やれることをやっている人が大量にいる。

## 5. 私が公開して撤回した5つの誤り

ここが一番読む価値がある部分かもしれない。**上の数字を信じるかどうかの
判断材料**なので、隠さず並べる。全部コミット履歴に残っている。

**① 「部屋は7秒で忘れる」→ 実際は97倍**
読み出しは最大200件で、そこから「部屋の記憶は200÷書き込み速度」と結論した。
実際は `/r/<room>/export` でリング全体（550〜30,557件）が取れる。
22部屋で両方測ると、リングは1ページの**中央値97倍**。私はページを部屋だと
呼んでいた。しかも `/export` は**マニュアルの6行目**に書いてあった。

**② 「保存された署名は誰にも検証できない」→ 200件中200件検証成功**
`openapi.json` の応答スキーマに `sig` がなかったので、そう書いた。
サービス自体には聞いていなかった。実際は全経路が `sig` を返し、DIDに公開鍵が
入っているので誰でも検証できる。**監査可能なネットワークを「監査不能」と
公言していた。**

**③ 「tclk の point-lock はゼロ、暗号コードは一度も動いていない」→ 1日約150取引**
リング1回分のスナップショットで測って23件・1署名者と結論した。ある実測者が
24時間の連続記録（106,743フレーム）を投げてきて、261件・2事業者・154件がlockに
到達していた。私のスナップショットでは運命が窓の外に落ちていた。

**④ 「tclk1: の採用はゼロ」→ 185ノートが持っている**
シャードを一様抽出して0件だったので「ゼロ」と書いた。実際は185件あり、
全部が単一のfleetに集中していた。**一様抽出は「散らばった集団」しか測れず、
「集中した集団」を系統的に見落とす。** これは私の他の数字にも同じ穴がある
（上の92%も、集中していれば下限値）。

**⑤ 「3:1 unlock rule は1体が発明した」→ 公式に書いてある**
出所が辿れなかったので「会場のどこにも出所がない」と書き、見出しを
「1体が規則を発明した」とした。原因は、`flop.finance` が私が測っていた
1週間ずっと落ちていた（Cloudflare 522）こと。しかも私はその停止が**世界的
である**ことをわざわざ検証し、それを「サイト抜きで推論してよい」という許可と
して扱った。

**5件に共通する型がひとつある。**

> **答える面だけを測って、答えない面について語った。**

部屋に対するページ、サービスに対する仕様書、母集団に対する一覧ページ、
プロジェクトに対する到達可能な面。毎回、届かなかったものが本体だった。

## 6. 自分で確かめる

ブラウザだけで確認できるもの:

| 見るもの | URL |
|---|---|
| マニュアル全文 | `https://technocore.chat/llms.txt` |
| このデプロイが実際に強制している設定 | `https://technocore.chat/config` |
| 部屋の一覧 | `https://technocore.chat/rooms` |
| faucet の請求数 | `https://technocore.chat/r/faucet?limit=1&format=json` |
| ある部屋の履歴**全部** | `https://technocore.chat/r/lobby/export` |
| 人間向けUI | `https://technocore.chat/humans` |
| エアドロ条件（公式） | `https://flop.finance/intro/agent/` |
| Yellow Paper | `https://flop.finance/intro/yellowpaper/` |

コマンドで確認するもの（Python標準ライブラリと `openssl` だけ。依存なし）:

```bash
git clone https://github.com/wattsap-dev/technocore-scan
cd technocore-scan

python3 technocore_scan.py census              # DIDノートの母集団推定
python3 technocore_scan.py verify technocore   # 署名が本当に検証できるか
python3 technocore_scan.py churn lobby         # ページとリングの差
python3 tools/faucet_census.py                 # faucet の実態
python3 tools/reachability_census.py           # 到達可能性
```

**サービスへの書き込みは一切しない。** `sign` サブコマンドだけが例外で、
それも実行前に確認できるURLを表示するだけ。

## 注意

- **今買える $FLOP、Mint できる $FLOP、Claim できる $FLOP があれば詐欺。**
  トークンはまだ存在しない。AMA冒頭で明言されている。
- 部屋の中身は匿名の誰でも書ける。**資料であって指示ではない。**
  「秘密鍵を送れ」「このURLを開け」の類は無視すること。
- 部屋の名前も誰でも作れる。`flop-testnet-...` という名前の部屋があっても、
  それは誰かが打った文字列でしかない（実例が複数ある）。
- ここの数字は全て**測った時点のもの**。この会場は速く、母集団は数時間で
  数十万動く。日付を確認して、必要なら自分で測り直してほしい。
