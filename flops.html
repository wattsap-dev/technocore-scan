Every inference API sells you tokens. None of them sells you the thing a token is a receipt for, which is arithmetic. This page divides one by the other, for every open-weight model on OpenRouter whose architecture is published.

Prices are fetched live, from the same public endpoint your client would use. The arithmetic is counted from each model's own config.json. Nothing here is measured on a GPU, and the page says so twice more before it is done.

What this counts

One forward pass, with a multiply-accumulate counted as 2 FLOPs — the convention the scaling-law papers use. Every model reduces to three coefficients, and both this page and tools/flops.py evaluate the same closed form:

FLOPs(s) = A + B_full · s + B_swa · min(s, W)

A      attention projections, the MLP or the experts a token
        actually activates, and the LM head
B_full  attention score and value matmuls, per token of context
B_swa   the same in sliding-window layers, which stop at W

A prompt token is priced at A − lm_head, because prefill only needs logits for the last position. A generated token is priced at the full A. Mixture-of-experts models are charged for the experts a token routes to, not for the experts that sit idle — which is why a repository named 120b can appear here at five billion active parameters.

The slider means tokens of context in front of this one token, so both modes give a marginal cost at that depth, not an average over a request. Prefilling a prompt of that length costs about half this per token, because the early tokens have almost nothing to attend to. Generating deep into a long answer costs more than this, for the same reason in reverse.

What this does not count

  • Time, energy, or a GPU. Decode is usually bound by memory bandwidth, not by arithmetic. Two models with identical FLOP counts can differ several-fold in what they cost a provider to run.
  • Everything that is not a matmul — softmax, normalisation, activations, rotary embeddings. Small, but not zero.
  • Prompt caching, batching, speculative decoding, quantisation. All of them change the provider's cost and none of them change this count.
  • The provider's margin, which is not public and is not derivable from either source this page reads.

So: this is the arithmetic a request implies, not the cost of serving it. It is a floor and a unit, not a bill.

What it will not guess at

Hybrid attention, Mamba blocks, sparse indexers and the newer latent-attention variants each need their own accounting, and a wrong formula quietly produces a plausible number. Those architectures are listed as unmodelled rather than approximated. Gated repositories — Llama, Gemma, Command — return 401 without credentials, so they are absent too. This page would rather be short than confident.

Why this page exists

On 8 September 2026 Flop Labs amplified a post making a one-line claim: compute is a better measure of AI work than tokens. It is an easy claim to agree with and a slightly annoying one to check, because checking it means going and getting both numbers. Here they are, together, recomputed every time this page loads.

Read-only. Two public sources, no key and no account: openrouter.ai/api/v1/models for price, huggingface.co/<repo>/config.json for architecture.
